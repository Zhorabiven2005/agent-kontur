# agent-kontur

Мой рабочий контур с агентами: правила и навыки для Claude Code, которыми я пользуюсь в системном анализе.

Я системный аналитик. Большая часть моей работы — разбирать требования, сверять их с кодом и находить, где система ведёт себя не так, как написано. Агент ускоряет поиск, решения и проверка остаются за мной.

## Как устроено

```
agent-kontur/
├── CLAUDE.md                     общие правила для агента; подключает rules/
├── rules/
│   ├── fact-check.md             не выдумывать: каждое утверждение — со ссылкой на источник
│   └── nda.md                    что нельзя отдавать агенту из рабочих материалов
├── .claude/skills/
│   ├── review-spec/              ревью постановки (ТЗ) до передачи в разработку
│   ├── code-vs-docs/             сверка кода и документации, реестр расхождений
│   └── vacancy-fit/              разбор вакансии под резюме: совпадения, пробелы, честный отклик
└── examples/
    ├── review-spec/              учебная постановка + эталон замечаний
    └── code-vs-docs/             учебный сервис + описание + эталон расхождений
```

- **CLAUDE.md** агент читает в начале каждой сессии в этой папке. Правила из `rules/` подключены через импорт `@rules/...`.
- **Навыки** лежат в `.claude/skills/` — Claude Code находит их сам и запускает, когда задача подходит под описание навыка, или по команде `/review-spec`, `/code-vs-docs`, `/vacancy-fit`.
- **Примеры** обезличены и придуманы. К каждому есть эталон: список ошибок, которые я заложил сам. По нему видно, что агент нашёл, что пропустил и где ошибся.

## Как проверяю агента

Агента проверяю как человека — на эталоне, а не на ощущении.

1. Готовлю документ с заранее известными ошибками (эталон).
2. Запускаю навык, сравниваю ответ с эталоном.
3. Считаю **полноту** (сколько заложенных ошибок найдено) и **точность** (какая доля замечаний агента — настоящие ошибки).
4. Если агент несколько раз пропускает один тип ошибки — добавляю отдельный шаг в навык. Повторилось — в навык.

Так появился шаг про «тихие» изменения поведения в `review-spec`: модели хорошо находят пропущенные поля и опечатки, но пропускают места, где меняется логика, а в тексте постановки это не названо.

## Быстрый старт

```bash
git clone https://github.com/Zhorabiven2005/agent-kontur
cd agent-kontur
claude
```

Дальше в Claude Code:

```
/review-spec examples/review-spec/spec.md
```

Сравнить результат с `examples/review-spec/expected.md`.
