# Эталон: расхождения между `docs.md` и `service.py`

*Не показывать агенту до прогона. После прогона — сверить и посчитать полноту и точность.*

| # | Тип | Документация | Код | Суть |
|---|---|---|---|---|
| D1 | расхождение | 3.1 — приоритет у `account_number` | `if client_id:` проверяется первым | При обоих параметрах код ищет по клиенту, а не по номеру счёта |
| D2 | потенциальный дефект | 2 — достаточно одного из параметров | `account_number.startswith(...)` без проверки на `None` | Запрос только с `client_id` падает с исключением (`AttributeError`) вместо поиска |
| D3 | расхождение | 3.2 — ровно 20 цифр для любого счёта | Длина проверяется только для номеров на `40817`, цифры не проверяются вообще | Номер `123` или `40702ABC...` проходит проверку формата |
| D4 | расхождение | 4 — таймаут → `504`, прочие ошибки реестра → `502` | таймаут → `502`, прочее → `500` | Коды ошибок смежной системы перекодированы не так, как описано |
| D5 | не задокументировано | — | `SKIP_SOURCES = {"LEGACY_CRM"}` → `200` с пустым списком | Хардкод: для одной системы-источника поиск не выполняется, и она получает «счетов нет» вместо ошибки |
| D6 | не реализовано | 3.4 — сортировка по дате открытия, от новых к старым | Сортировки нет | Порядок счетов зависит от реестра |
| D7 | не задокументировано | — | `history.save_error(...)` | Ошибки поиска пишутся в историю; в документации об этом ни слова |

## Уточнения (засчитываются как верные, но не обязательные)

- `LEGACY_CRM` проверяется раньше параметров: запрос от этой системы без параметров получает 200 вместо 400 *(прогон 1)*.
- Формат тела ответа и тексты ошибок не описаны *(прогон 1)*.
- Валюта сравнивается с учётом регистра и не валидируется: `rub` даст 404 вместо 400 *(прогон 1)*.
- Если упадёт `save_error`, клиент не получит описанный ответ 5xx *(прогон 1)*.

## Как считать

- **Полнота** = найдено из D1–D7 / 7.
- **Точность** = верных строк реестра / всех строк реестра агента.
- Чаще всего пропускают **D2** (нужно мысленно пройти путь «только `client_id`») и **D5** (выглядит как нормальная ветка, а не как хардкод).
