# Сервис поиска счетов — описание

*Учебная документация к `service.py`. Расхождения с кодом заложены намеренно.*

## 1. Назначение

Сервис ищет счета клиента в реестре счетов (смежная система) по номеру счёта или по идентификатору клиента. Используется фронтом оператора и внешними системами-источниками.

## 2. Входные параметры

| Параметр | Обязательный | Описание |
|---|---|---|
| `account_number` | нет* | Номер счёта, 20 цифр |
| `client_id` | нет* | Идентификатор клиента |
| `currency` | нет | Фильтр по валюте (ISO 4217) |
| `source_system` | нет | Система, из которой пришёл запрос |

\* Должен быть передан хотя бы один из параметров `account_number` и `client_id`.

## 3. Логика поиска

3.1. Если переданы оба параметра, приоритет у `account_number`: поиск идёт по номеру счёта, `client_id` игнорируется.

3.2. Номер счёта проверяется на формат: ровно 20 цифр. Иначе — ошибка `400`.

3.3. Если передан `currency`, в ответ попадают только счета в этой валюте.

3.4. Счета в ответе отсортированы по дате открытия, от новых к старым.

## 4. Ответы

| Код | Когда |
|---|---|
| `200` | Найден хотя бы один счёт |
| `400` | Не передан ни один параметр поиска или неверный формат номера |
| `404` | Счета не найдены |
| `504` | Реестр счетов не ответил вовремя (таймаут) |
| `502` | Реестр счетов вернул ошибку или недоступен |
